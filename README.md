# เลขาส่วนตัวใน LINE OA — ต้นแบบสำเร็จรูป

| ทำอะไรได้ | ลองพิมพ์/ส่งใน LINE |
|---|---|
| จำข้อมูลให้ | "จดไว้ รหัส wifi บ้าน 12345678" → อาทิตย์หน้าถาม "รหัส wifi อะไรนะ" ก็ตอบได้ |
| **ลืมให้ด้วย** | "ลืมรหัส wifi ได้แล้ว" · "ลืมโน้ต 3" — ตรงหลายอันมันจะถามกลับก่อน ไม่เดาลบ |
| **ค้นของเก่า** | "เคยคุยเรื่องราคาไว้ว่าไง" · "กลุ่มโซลาร์เมื่อวานสรุปว่าอะไร" → ค้นข้อความย้อนหลังให้ |
| งานที่ต้องทำ | "เตือนส่งงานลูกค้าพรุ่งนี้ 10 โมง" · "มีอะไรต้องทำบ้าง" · "ปิดงาน 2" |
| **ถึงกำหนดแล้วเตือนจริง** | ถึงเวลาที่สั่งไว้ บอททักหาเองในแชท (เวลาไทยเสมอ ไม่ต้องคำนวณ) |
| **ส่งสลิป → บันทึกรายจ่าย** | ส่งรูปสลิปเข้าไปเฉย ๆ → "บันทึกแล้ว 120 บาท · เดือนนี้ใช้ไป 3,450" |
| **พูดแทนพิมพ์** | อัดเสียงส่ง "นัดหมอศุกร์บ่ายสอง" → ถอดเสียงแล้วจดให้เลย |
| รวมยอดรายจ่าย | "เดือนนี้ใช้เงินไปเท่าไหร่" |
| **ยอดขายรายวัน** | "ยอดวันนี้ สินค้า A 12,000 สินค้า B 8,500" → บันทึก + เทียบเมื่อวาน (ส่งซ้ำ = แก้ยอด) |
| **สรุปยอด 7 วัน + เทรนด์ %** | "สรุปยอด 7 วัน" → รายวัน · สัดส่วนสินค้า % · ขึ้น/ลงเทียบช่วงก่อน · ทุกวันจันทร์ส่งสรุปสัปดาห์ให้เอง |
| **สรุปกลุ่มสด** | พิมพ์ในกลุ่มว่า "เลขา สรุปให้หน่อย" → สรุป + งานที่ค้างทันที |
| **สรุปกลุ่มอัตโนมัติ** | 8 โมงเช้า / 6 โมงเย็น สรุป **ทุกกลุ่มรวมเป็นข้อความเดียว** + ลิงก์กระดาน (อยู่ 20 กลุ่มก็ยังกินโควตาแค่ 2 ข้อความ/วัน) |
| **สรุปแล้วรู้ว่าใครพูด** | ดึงชื่อคนในกลุ่มจาก LINE มาใส่ให้ → "เอถามราคา รอตอบ" ไม่ใช่ "มีคนถามราคา" |
| **คำต้องห้าม → เตือนทันที** | มีคนพิมพ์ "ยกเลิก / คืนเงิน / ไม่พอใจ / ด่วน" ในกลุ่มไหนก็เด้งหาเจ้าของทันที |
| **ลูกค้าถามค้าง → เตือน** | ในกลุ่มมีคำถามแล้วเงียบเกิน 15 นาที → เตือนว่ายังไม่มีใครตอบ |
| **สรุปออเดอร์** | กลุ่มสั่งของ → สกัดออเดอร์ + รวมยอดแนบมากับรายงาน |
| **สลิปในกลุ่ม → ปิดยอด** | ลูกค้าส่งสลิปในกลุ่มรับออเดอร์ → จับคู่ออเดอร์ยอดเท่ากันแล้วมาร์คว่าจ่ายแล้ว |
| **ตั้งค่ากลุ่มด้วยปาก** | "กลุ่มนี้รายงาน 9 โมงกับ 5 โมงเย็น" · "เพิ่มคำเตือน ช้ามาก" · "หยุดเฝ้ากลุ่มนี้" |
| **ปฏิทิน** | "วันนี้มีนัดอะไร" · "อาทิตย์นี้ติดอะไรบ้าง" + แปะตารางไว้หัวรายงานเช้า (ต่อได้ 2 แบบ: ลิงก์ iCal ลับ หรือ Service Account) |
| **ค้น Google Drive** | "ไฟล์ราคาส่งอยู่ไหน" · "ในชีตยอดขายเดือนนี้เท่าไหร่" → ค้นแล้วอ่านเนื้อหามาตอบ (เห็นเฉพาะโฟลเดอร์ที่แชร์ให้) |
| **ปุ่มลัดใต้แป้นพิมพ์** | `node scripts/rich-menu.mjs` → ได้ 4 ปุ่ม: สรุปวันนี้ · งานค้าง · รายจ่าย · เปิดกระดาน |
| **token ต่ออายุเอง** | token ของ LINE มีอายุ 30 วัน หมดแล้วบอทเงียบสนิท — ใส่ `LINE_CHANNEL_ID` แล้วระบบออกใหม่เองตั้งแต่เหลือ 2 วัน ไม่ต้องมาต่อด้วยมืออีกเลย |
| **บอทตายแล้วรู้** | `/api/health` เช็ค DB · token LINE ใกล้หมดอายุ · โควตา push · เครดิต AI · cron ยังเดินไหม — เจอปัญหาทักเตือนเจ้าของเอง |

## ใช้อะไรบ้าง (เริ่มต้นฟรีทั้งหมด)

| ตัว | หน้าที่ | ราคา |
|---|---|---|
| **LINE OA** | หน้าร้าน — ที่คนพิมพ์คุย | ฟรี (push 300 ข้อความ/เดือน · ตอบแชทไม่นับ) |
| **OpenRouter** | สมอง — คิด ตัดสินใจใช้เครื่องมือ สรุปกลุ่ม | จ่ายตามใช้ หลักสตางค์ต่อข้อความ |
| **Vercel** | หู — รับ webhook + dashboard + cron สรุปวันละครั้ง | ฟรี |
| **Neon** | ความจำ — เก็บทุกอย่างถาวร (กดสร้างในหน้า Vercel) | ฟรี |
| **Railway** *(ไม่บังคับ)* | อยากได้รายงานถี่กว่าวันละครั้ง + เตือนลูกค้าถามค้าง | $5/เดือน |

> **ถ้าทีม Vercel ของคุณเป็นแผน Pro อยู่แล้ว ไม่ต้องจ่าย Railway เลย** — Pro ตั้ง cron ถี่ได้:
> เปลี่ยน `schedule` ใน [vercel.json](vercel.json) เป็น `*/10 * * * *` แล้วตั้ง env `CRON_FREQUENT=1`
> จะได้ครบทั้งสรุปตามเวลาใน `report_hours` (เช้า-เย็น) และเตือนลูกค้าถามค้าง เท่ากับแบบ $5 ทุกอย่าง
> (แผนฟรี/Hobby ตั้งได้แค่วันละครั้ง ถ้าใส่ `*/10` จะ deploy ไม่ผ่าน)

**ไม่จ่าย Railway ก็ใช้ได้เกือบครบ** — Vercel แผนฟรีตั้งเวลาได้วันละครั้ง (คลาดได้ถึง 1 ชม.) พอสำหรับ "สรุปตอนเช้า"
ที่ต้องจ่ายจริง ๆ มีอย่างเดียวคือ **เตือนลูกค้าถามค้างเกิน 15 นาที** เพราะต้องเช็คทุก 10 นาที
ส่วน**เตือนคำต้องห้าม** ไม่ต้องใช้ Railway — ทำในตัว webhook เด้งทันทีอยู่แล้ว

**กฎที่ตัดสินทั้งระบบ: หู ≠ สมอง** — webhook แค่เขียนข้อความลงฐานข้อมูลแล้วตอบ 200 ทันที ไม่เรียก AI (กลุ่มหนึ่งมี 500+ ข้อความ/วัน ถ้ายิง AI ทุกข้อความคือจ่ายค่า token ให้คำว่า "555" และช้าจน LINE ตัดการเชื่อมต่อ) แล้วให้ worker บน Railway มาสรุปเป็นรอบ

```
คนพิมพ์ในกลุ่ม → Vercel /api/line → เขียนลง Neon → ตอบ 200 (จบใน 0.3 วิ)
คนพิมพ์หาเลขาตรง ๆ (แชท 1:1 หรือขึ้นต้นว่า "เลขา") → เรียก AI ตอบทันที
ตามรอบเวลา → สรุปกลุ่ม → push เข้าแชท 1:1 ของเจ้าของ
     · แบบฟรี: Vercel cron ยิง /api/cron วันละครั้ง ~8 โมงเช้า
     · แบบ $5: Railway worker วนทุก 10 นาที (รายงานได้หลายรอบ + เตือนลูกค้าถามค้าง)
```

## ติดตั้ง — มือใหม่ทำเสร็จใน 2 ชั่วโมง

**ไม่ต้องเขียนโค้ดเอง** ให้ Claude Code ติดตั้งให้ หน้าที่เราคือสมัครบริการแล้วส่งค่าให้มัน

### 1. สมัคร 4 อย่างนี้ก่อน (ทำในเว็บ ~20 นาที)

| สมัครที่ | ได้อะไรมา | เตรียม |
|---|---|---|
| [manager.line.biz](https://manager.line.biz) | สร้าง OA + เปิด Messaging API → ได้ Channel secret | บัญชี LINE |
| [developers.line.biz](https://developers.line.biz) | Channel access token (กด Issue) + **Channel ID** | บัญชีเดียวกัน |
| [openrouter.ai](https://openrouter.ai) | API key | บัตร (เติม $5) |
| [vercel.com](https://vercel.com) | — (แค่สมัครไว้) | GitHub |
| Neon | **ไม่ต้องสมัครแยก** — กดสร้างในหน้า Vercel → Storage ตอนติดตั้ง | — |
| [railway.app](https://railway.app) *(ทำทีหลังได้)* | — | บัตร $5/เดือน |

⚠️ **ข้อที่คนพลาดเยอะสุด** — ที่ [manager.line.biz](https://manager.line.biz) → **การตั้งค่า → การตอบกลับ** → **ปิด** "ข้อความตอบกลับอัตโนมัติ" กับ "ข้อความต้อนรับ" (ถ้าไม่ปิด บอทจะเงียบเพราะโดนข้อความสำเร็จรูปแย่งตอบ)
สวิตช์ **Webhook** ในหน้าเดียวกันยังเปิดไม่ได้ตอนนี้ — ต้องมี URL ก่อน เดี๋ยว Claude พากลับมาเปิดหลัง deploy เสร็จ

### 2. เปิด Claude Code แล้ววาง prompt นี้

```
ช่วยติดตั้งเลขา LINE OA ให้หน่อย ผมไม่เคยเขียนโค้ดมาก่อน
โค้ดอยู่ที่ https://github.com/gobank01/line-secretary
โคลนมาแล้วทำตาม INSTALL.md ในโปรเจค ถามผมทีละขั้นนะ
```

Claude จะพาทำทีละขั้นแบบ wizard **10 ขั้น** — บอกให้สมัครทีละเว็บ ขอค่าทีละตัว
และ**ตรวจให้เห็น ✅ ก่อนถึงจะไปขั้นถัดไป** (ไม่ใช่ไปพังตอนจบ) ทำค้างไว้แล้วปิดแชทได้ กลับมาบอกว่า "ทำต่อ" มันจำได้ว่าถึงไหน

```
[ขั้น 5/10] ✅✅✅✅⬜⬜⬜⬜⬜⬜ — สมัคร OpenRouter
✅ ต่อ LINE OA ได้: "เลขาน้องมิ้น" (@123abcd)
```

ค่าทั้งหมดถูกเขียนลงไฟล์ `.env.local` ในเครื่องตัวเอง ไม่ถูกส่งไปไหน

### 3. ขั้นสุดท้าย Claude จะถามว่า "อยากให้บอททำหน้าที่อะไร"

ทำธุรกิจอะไร · อยากให้เรียกคุณว่าอะไร · ให้ช่วยเรื่องไหนมากที่สุด · อะไรที่ห้ามทำ
แล้วมันจะเขียน [lib/persona.js](lib/persona.js) ให้ตรงกับธุรกิจคุณ — **นี่คือขั้นที่ทำให้บอทเป็นของคุณ ไม่ใช่บอทสำเร็จรูปที่เหมือนกันทุกคน**

เปลี่ยนใจทีหลังก็บอก Claude ได้ตลอด: "แก้ persona ให้เรียกผมว่าเฮีย พูดห้วนกว่านี้" · "เพิ่มเครื่องมือจดวันเกิดลูกค้า" · "เปลี่ยนเวลารายงานเป็น 7 โมงกับ 3 ทุ่ม"

### เช็คว่าใช้ได้จริง

ทักบอทในแชทส่วนตัว:
> จดไว้หน่อย รหัส wifi บ้าน 12345678
> เตือนส่งงานลูกค้าพรุ่งนี้ 10 โมง
> มีอะไรต้องทำบ้าง

แล้วเชิญ OA เข้ากลุ่ม → บอทแนะนำตัว → 8 โมงเช้ากับ 6 โมงเย็นจะได้สรุปเข้าแชทส่วนตัว
(แก้เวลาได้ที่ตาราง `watched.report_hours`)

ดูทุกอย่างที่ `https://ชื่อโปรเจค.vercel.app/dashboard?key=DASHBOARD_KEY`
— หน้านี้รวม: เรื่องด่วนที่ต้องรู้ทันที · งานค้าง · ของที่จดไว้ · กลุ่มที่เฝ้า · รายจ่ายรายหมวด+รายวัน · ออเดอร์ · สรุปบทสนทนาแยกวัน
เติม `&demo=1` = ดูหน้าตาด้วยข้อมูลสมมุติ (ยังไม่มีข้อมูลจริงก็ดูได้) · ตั้ง env `DASHBOARD_PUBLIC=1` = เปิดให้ใครก็เข้าได้ ไม่ต้องมี key

| [app/api/health/route.js](app/api/health/route.js) | ตรวจสุขภาพระบบ — เสียบ uptime monitor ได้ (ปกติ 200 · มีปัญหา 503) |
| [vercel.json](vercel.json) / [railway.json](railway.json) | ตั้งเวลา cron / Start Command — มีให้แล้ว ไม่ต้องไปกดในเว็บ |
| [lib/brain.js](lib/brain.js) | เรียก OpenRouter + เครื่องมือ 13 ตัว (เพิ่มเครื่องมือใหม่ที่นี่) + สรุป/อ่านสลิป/ถอดเสียง |
| [lib/db.js](lib/db.js) | Neon — ความจำ + เก็บข้อความดิบ |
| [lib/line.js](lib/line.js) | ตรวจลายเซ็น + reply + push |
| [lib/persona.js](lib/persona.js) | **หน้าที่และบุคลิกของบอท** — แก้ไฟล์เดียวเปลี่ยนตัวตนได้ทั้งตัว (หรือตั้ง env `PERSONA` ทับ ไม่ต้อง deploy) |
| [lib/calendar.js](lib/calendar.js) | อ่านปฏิทินผ่านลิงก์ iCal ลับ (ทางง่าย ไม่ต้องตั้งอะไรใน Google Cloud) |
| [lib/google.js](lib/google.js) | ต่อ Calendar + Drive ด้วย Service Account (ทางเต็ม — ค้นไฟล์ อ่านเอกสาร/ชีตได้) |
| [lib/schema.js](lib/schema.js) | ตารางทั้งหมด — สร้างให้ตอนติดตั้ง |
| [scripts/rich-menu.mjs](scripts/rich-menu.mjs) | สร้างปุ่มลัดใน LINE (วาดรูปด้วย Chrome + อัปโหลดให้เสร็จในคำสั่งเดียว · `--off` เอาออก) |
| [scripts/setup.mjs](scripts/setup.mjs) | ติดตั้งอัตโนมัติ — สร้างตาราง + ตั้ง webhook + ยิงทดสอบ |
| [scripts/check.mjs](scripts/check.mjs) | ตรวจทีละบริการว่าค่าที่ใส่ใช้ได้จริง (`line` / `openrouter` / `db` / `vercel <url>` / `all`) |
| [scripts/push-env.mjs](scripts/push-env.mjs) | ส่งค่าจาก `.env.local` ขึ้น Vercel/Railway ทั้งชุด (ค่าไม่โผล่บนหน้าจอ) |
| [INSTALL.md](INSTALL.md) | wizard 10 ขั้น — คู่มือสำหรับ Claude Code ที่ช่วยผู้ใช้ติดตั้ง |

`npm test` = เช็คลายเซ็น LINE กับตรรกะ to-do (ไม่ต้องต่อเน็ต ไม่ต้องมี DB)

`npm run audit` = ตรวจช่องโหว่ของ dependency ที่ใช้บน Production · ต้องได้ 0 vulnerabilities

`npm run verify` = รันทดสอบทั้งหมด + production build + security audit ก่อน deploy

เปิดหน้าแรกของเว็บ = ตรวจสุขภาพ บอกเองว่าค่าไหนยังไม่ใส่ / ตารางสร้างหรือยัง

| ไม่อยากให้บอทพูดในกลุ่มเลย | ตั้ง `GROUP_SILENT=1` — เรียก "เลขา ..." ในกลุ่ม คำตอบไปเข้าแชทส่วนตัวแทน |
| สมองหลักอ่านรูปไม่ได้ (เช่น DeepSeek V4) | ตั้ง `OPENROUTER_VISION_MODEL=google/gemini-2.5-flash` ไว้อ่านสลิป |
| deploy แล้ว Vercel ฟ้อง `.next` not found | Vercel ไปหยิบ buildCommand ของ `railway.json` — `vercel.json` ระบุ `next build` ไว้แล้ว |
| คนอื่นแอด OA แล้วทัก บอทเงียบ | **ตั้งใจให้เป็นแบบนั้น** — ค่า default ตอบเฉพาะ `OWNER_USER_ID` · อยากให้ตอบทุกคนตั้ง `REPLY_TO_ALL=1` |
| Verify ไม่ผ่าน | ยังไม่ redeploy หลังใส่ env / URL พิมพ์ตก `/api/line` |
| บอทเงียบ ทั้งที่ทุกอย่างถูก | **ยังไม่ได้เปิดสวิตช์ Webhook** (ต้องเปิดหลังใส่ URL แล้วเท่านั้น) หรือ `LINE_CHANNEL_SECRET` ผิด (Vercel log จะเห็น 401) |
| ตอบเป็นข้อความสำเร็จรูป | ยังไม่ปิด Auto-reply messages |
| เชิญเข้ากลุ่มไม่ได้ | ยังไม่เปิด Allow bot to join group chats |
| ถามเรื่องที่คุยเมื่อกี้แล้วจำไม่ได้ | บทสนทนาจำ 24 ข้อความล่าสุด (ปรับที่ env `CHAT_MEMORY`) · ของที่ "จดไว้" ไม่ลืม · เรื่องเก่ากว่านั้นสั่งให้ "ค้นย้อนหลัง" ได้ |
| ตั้งเวลาเตือนแล้วเงียบ | cron ไม่ได้รัน (แผนฟรียิงวันละครั้ง — งานที่ครบกำหนดตอนบ่ายจะไปเตือนรอบเช้าวันรุ่งขึ้น) · ทีม Pro ตั้ง `*/10` + `CRON_FREQUENT=1` แล้วเตือนตรงเวลา |
| จู่ ๆ บอทเงียบหลังใช้มา ~1 เดือน | token หมดอายุ (30 วัน) — ใส่ `LINE_CHANNEL_ID` ไว้แล้วจะไม่เจอปัญหานี้อีก · เช็คได้ที่ `/api/health` ดู `token_days` กับ `mode.auto_token` |
| อยู่หลายกลุ่มแล้วบอทเงียบกลางเดือน | โควตา push ฟรีหมด (300/เดือน) — เปิด `/api/health` ดูว่าเหลือเท่าไหร่ |
| ไม่มีรายงานเข้า | `OWNER_USER_ID` ว่าง / worker ไม่ได้รัน (ดู Railway Logs) / ยังไม่ถึงชั่วโมงใน `report_hours` |
| too many connections | ใช้ connection string ที่ไม่มี `-pooler` |
